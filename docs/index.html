はじめかた

  1. Cross Campus を準備 — プロフィールを入力し、電話番号を認証しておくと SMS 認証が不要になります。
  2. gcvote を起動して告知文を貼り付け、Enter を2回押して確定。
  3. 初回だけブラウザで Cross Campus にログインし、4つの質問（公開への同意・卒業見込み年度・団体との関係性・知ったきっかけ）に答えます。次回からは不要です。
  4. 内容を確認して y で送信。

コマンド

gcvote告知文や URL を貼り付けて投票
gcvote 告知文.txt告知文をファイルで渡す（URL を直接渡すことも可）
gcvote -dry-run …送信せず、内容と投票済みかどうかを確認
gcvote -m 'メッセージ' …応援メッセージを指定
gcvote -y …確認なしで送信
gcvote config保存した回答を設定し直す
gcvote login / logoutログインし直す / ログイン情報を削除
gcvote versionバージョンを表示

応援は1つの大学につき1人1回までです。オプションは URL やファイル名より前に書いてください。

困ったとき

ログイン後、ターミナルに戻ってこない

アドレスバーの …/auth/callback?token=… の URL をターミナルに貼り付けて Enter。

だめなら、投票フォームで Cross Campus にログインし、そのタブのコンソールで次を実行して出た値を貼り付けます。

sessionStorage.getItem("cc_session_id")
Mac で「開発元を検証できないため開けません」と出る

上の curl … | sh でインストールするか、次を実行してください。

xattr -d com.apple.quarantine ./gcvote
SMS 認証を求められる

Cross Campus で電話番号が未認証です。届いた8桁のコードを入力してください（r で再送）。

「プロフィールに未入力の項目があります」と出る

Cross Campus のプロフィールに入力漏れがあります。入力してから再実行してください。

自分の大学の団体に投票したい

現在は他大学への投票のみ対応しています。自分の大学はサイトから投票してください。

急に動かなくなった

サイトの仕様変更の可能性があります。gcvote version の結果を添えて Issues へ。

個人情報について

名前や電話番号は Cross Campus から毎回取得し、gcvote には保存しません。保存するのはログイン情報とフォームの回答だけで、本人だけが読める設定ディレクトリ（macOS: ~/Library/Application Support/gcvote/）に置かれます。

公式の API ではないため、サイトの更新で動かなくなることがあります。自分のアカウントでの投票を楽にするためのツールです。
